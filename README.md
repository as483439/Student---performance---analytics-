Student Performance Analytics System

Project Description

This project analyzes student performance using Python, Pandas, and NumPy.

Features

- Calculates total marks and average marks.
- Assigns grades to students.
- Identifies Pass and Fail students.
- Displays class statistics.
- Calculates subject-wise averages.
- Identifies the top 3 students.
- Analyzes student attendance.

Files

- "Main.py" — Python source code.
- "Students.csv" — Student dataset.

How to Run

Keep "Main.py" and "Students.csv" in the same folder and run "Main.py" using Python with Pandas and NumPy installed.

Output

The program displays student results, grades, class statistics, subject averages, top performers, and attendance analysis.
